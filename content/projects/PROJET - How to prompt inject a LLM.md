# Context of this project
A large language model (LLM) given the power to act, for instance read data, use call tools, move information is thrustworthy only if they can follow legitimate instructions from malicious ones.
But they don't separate instructions from data, everything is just tokens in the same context window. This project demonstrates, in a <ins>**controlled lab**</ins>, how that single flaw becomes a working prompt injection, why the usual defenses don't hold, and how far mitigation can realistically go.
